Core Implementation

1. Strategy Configuration Module (src/strategy/config.py)

StrategyConfig dataclass with complete YAML schema support
IndicatorConfig for RSI and EMA indicators
EntryCondition supporting: less_than, greater_than, cross_above, cross_below
ExitCondition supporting: take_profit, stop_loss, time_exceeds, support_resistance, end_of_day
RiskParameters for optional risk management settings
Comprehensive validation for all configuration fields
load_strategy_from_yaml() function with error handling

2. Strategy Directory Loader (src/strategy/loader.py)

StrategyLoader class for managing multiple strategies
Loads all YAML files from a configured directory
Handles invalid strategies with proper error logging
Prevents duplicate strategy names
Methods for getting, checking, reloading, and removing strategies

3. File Watcher (src/strategy/watcher.py)

StrategyWatcher class using the watchdog library
Monitors strategy directory for file changes (create, modify, delete)
Triggers async callbacks on file events
Proper start/stop lifecycle management
